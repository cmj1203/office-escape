# 야근 탈출: 컷신 대본

작성일: 2026-09-30 (같은 날 계단 연출과 새 결말로 고침). 상태: **게임에 반영됨.**

## 1. 확정된 것

| 항목 | 결정 |
|---|---|
| 사연 | 오늘은 딸의 여섯 번째 생일이다 |
| 시작 시각 | 오후 6시. 퇴근할 시간 |
| 막차 | 뺐다. 게임 어디에도 나오지 않는다 |
| 엘리베이터 | 마침 정기 점검 중이라 탈 수 없다. 그래서 계단으로 내려간다 |
| 층 이동 | 층 보스를 잡으면 비상계단 문이 열리고, 김 과장의 눈으로 계단을 내려가는 연출(1인칭)이 나온다 |
| 케이크 | 처음부터 끝까지 홀케이크. 결말에서 식탁에 앉아 함께 촛불을 분다 |
| 시계 | 18:00 에서 시작해 한 층에 한 시간씩. 23:00 에 부장님 등장 |
| 부장님 | 입사 동기. 자기도 아이 생일을 놓친 적이 있다 (답을 받지 못해 추천안으로 넣음. 대사만 바꾸면 됨) |

## 2. 장면 목록

대사를 고치려면 `index.html` 의 `CUTSCENES` 표를 고치면 된다.

### 시작 (4장면)

| 번호 | 그림 파일 | 글 |
|---|---|---|
| 1 | story_open | 오후 6시. 퇴근할 시간이다. 가방을 들었다. / 메일 알림이 울렸다. |
| 2 | story_gift | 오늘은 딸의 여섯 번째 생일이다. / 작년에도, 재작년에도 늦었다. |
| 3 | story_promise | "촛불은 아빠가 와야 불 거야." / 오늘은 꼭 간다. |
| 4 | story_noelev | 엘리베이터는 마침 정기 점검 중이었다. / 계단으로 간다. 다섯 층만 내려가면 된다. |

### 계단 (층을 내려갈 때마다 2장면)

첫 장면은 김 과장의 눈으로 본 계단 그림(story_stairs: 계단 아래 문, 오른손의 가방)이 걸음마다 출렁이며 아래층 문 쪽으로 다가가는 움직임이다. 다 내려가면 저절로 둘째 장면으로 넘어간다.

| 구간 | 걷는 장면의 층 표시와 글 | 둘째 장면 그림 | 둘째 장면 글 |
|---|---|---|---|
| 5층에서 4층 | 5F → 4F / 비상계단으로 내려간다. | story_stair1 | 문자가 왔다. "아빠 언제 와?" / "금방 가." |
| 4층에서 3층 | 4F → 3F / 한 층 더. | story_stair2 | 부재중 전화 두 통. / 회의 중이라 받지 못했다. |
| 3층에서 2층 | 3F → 2F / 다리가 후들거린다. | story_stair3 | "케이크 꺼내 놨어. 촛불은 아직 안 켰어." |
| 2층에서 1층 | 2F → 1F / 마지막 계단이다. | story_stair4 | "아빠, 나 졸려." / 1층이다. 이 문만 나서면 된다. |

### 결말 (3장면, 부장님을 이긴 뒤. 굿엔딩 / 노말엔딩)

시작부터 부장님을 잡을 때까지 **15분 안**이면 굿엔딩, 넘으면 노말엔딩 (`GOOD_ENDING_TIME`). 앞 두 장면은 같고 마지막 장면만 다르다.

| 번호 | 그림 파일 | 글 |
|---|---|---|
| 1 | story_end1 | 부장님: "...나도 우리 애 생일을 세 번 놓쳤지." / "들어가 봐. 뛰어." |
| 2 | story_clear | 지하철 창가. 가방을 꼭 안았다. |
| 3 굿엔딩 | story_home_good | 문을 열자마자 아이가 달려와 안겼다. / "촛불은 아빠가 와야 분다고 했잖아." 같이 불었다. |
| 3 노말엔딩 | story_home | 밤 11시 50분. 식탁에서 졸던 아이를 깨웠다. / "아빠 왔어. 같이 촛불 불자." |

결말 뒤에 결과 창이 나온다: 굿엔딩 "생일 축하해. 아빠 왔어." / 노말엔딩 "생일 축하해. 늦어서 미안." + 어느 엔딩인지와 기준 시간, 걸린 시간, 처치 수, 레벨. 결과 창에는 그림이 없다 (바로 앞 장면과 같은 그림이 두 번 나오지 않게, 2026-09-30).

### 게임오버 (죽은 이유마다 1장면, 그 뒤 결과 창)

층 보스가 나와 있을 때 죽으면 그 보스의 장면, 아니면 일반 적 장면. 결과 창에는 같은 그림과 "새벽 2시. 문자가 와 있었다. / "아빠 나 먼저 잘게. 사랑해."" 가 나온다 (2026-09-30 사용자가 정한 문구).

| 죽은 이유 | 그림 파일 | 글 |
|---|---|---|
| 일반 적 | story_over_work | 일에 파묻혔다. 자정이 지났다. / 휴대폰은 서류 더미 밑에서 울리고 있었다. |
| 5층 옆 팀 팀장 | story_over_5f | "이것만" 이 열 개가 됐다. / 옆 팀 일을 새벽까지 봐 줬다. |
| 4층 끝나지 않는 주간 회의 | story_over_4f | 회의는 끝나지 않았다. / 안건 12번에서 눈을 떴다. 새벽 2시. |
| 3층 인사팀장 | story_over_3f | 면담은 길었다. / "평가에 반영하겠습니다." 딸 생일 이야기는 꺼내지 못했다. |
| 2층 감사팀장 | story_over_2f | 영수증 한 장을 찾다 밤이 샜다. / 찾았을 땐 이미 자정이었다. |
| 1층 부장님 | story_over_1f | "한 잔만" 이 세 병이 됐다. / 휴대폰이 계속 울렸다. 받지 못했다. |

예전 게임오버 그림(story_over, 책상에 엎드려 잠듦)은 더 쓰지 않는다 (`_old/` 에 보관).

## 3. 조작

| 키 | 동작 |
|---|---|
| Enter, Space, 클릭 | 다음 장면 (걷는 중에 누르면 걷기를 건너뛰고 바로 다음 장면) |
| Esc | 컷신 전체 건너뛰기 |

## 4. 그림

이야기 그림 19장과 비상계단 문 아이콘 1장이다. 그림에는 글자를 넣지 않았고, 문자 내용은 아래 글로 보여 준다.

| 묶음 | 그림 |
|---|---|
| 시작 | story_open, story_gift, story_promise, story_noelev |
| 계단 | story_stairs (1인칭 계단 배경), story_stair1, story_stair2, story_stair3, story_stair4 |
| 결말 | story_end1, story_clear, story_home_good (굿엔딩), story_home (노말엔딩) |
| 게임오버 | story_over_work, story_over_5f, story_over_4f, story_over_3f, story_over_2f, story_over_1f |
| 게임 안 | stairs (보스를 잡으면 나타나는 비상계단 문 아이콘) |

쓰지 않게 된 엘리베이터 그림, 예전 결말 그림, 옆에서 본 계단 그림(story_stairs_side)은 `assets/office/_old/` 에 보관했다.

## 5. 고치고 싶을 때

| 고치고 싶은 것 | 방법 |
|---|---|
| 대사 | `CUTSCENES` 표의 `lines` 를 고친다 |
| 장면 추가 | `panels` 에 한 줄 추가 (`img` 는 assets/office 폴더의 그림 이름) |
| 버튼 글자 | `doneLabel` |
| 글이 나타나는 속도 | `CUTSCENE_LINE_DELAY` |
| 굿엔딩 기준 시간 | `GOOD_ENDING_TIME` (초, 지금 15분) |
| 계단을 내려가는 속도 | `STAIRS_WALK_TIME` (초) |
| 걸음 수, 출렁임, 좌우 흔들림 | `STAIRS_WALK_STEPS`, `STAIRS_WALK_BOB`, `STAIRS_WALK_SWAY` |
| 얼마나 다가가는지 | `STAIRS_WALK_ZOOM_FROM` → `STAIRS_WALK_ZOOM_TO` (배율) |
| 다가가는 곳 | `STAIRS_WALK_FOCUS` (그림 속 아래층 문의 위치 %. 계단 그림을 바꾸면 맞춰야 함) |
