# 야근 탈출: 컷신 대본

작성일: 2026-09-30 (같은 날 계단 연출과 새 결말로 고침. 10-01 계단 장면을 휴대폰 진동·문자 확인으로 바꿈). 상태: **게임에 반영됨.**

## 1. 확정된 것

| 항목 | 결정 |
|---|---|
| 사연 | 오늘은 딸의 여섯 번째 생일이다 |
| 시작 시각 | 오후 6시. 퇴근할 시간 |
| 막차 | 뺐다. 게임 어디에도 나오지 않는다 |
| 엘리베이터 | 마침 정기 점검 중이라 탈 수 없다. 그래서 계단으로 내려간다 |
| 층 이동 | 층 보스를 잡으면 비상계단 문이 열리고, 김 과장의 눈으로 계단을 내려가는 연출(1인칭)이 나온다. 내려가는 도중 주머니 속 휴대폰이 울리고, 화면을 누르면 딸이 보낸 문자를 본다 (10-01) |
| 케이크 | 처음부터 끝까지 홀케이크. 결말에서 식탁에 앉아 함께 촛불을 분다 |
| 시계 | 18:00 에서 시작해 한 층에 한 시간씩. 23:00 에 부장님 등장 |
| 부장님 | 입사 동기. 자기도 아이 생일을 놓친 적이 있다 (답을 받지 못해 추천안으로 넣음. 대사만 바꾸면 됨) |

## 2. 장면 목록

대사를 고치려면 `index.html` 의 `CUTSCENES` 표를 고치면 된다.

### 시작 (4장면)

| 번호 | 그림 파일 | 글 |
|---|---|---|
| 1 | story_open | 오후 6시. 퇴근할 시간이다. 가방을 들었다. / 메일 알림이 울렸다. |
| 2 | story_gift | 오늘은 딸의 여섯 번째 생일이다. / 작년에도, 재작년에도 늦었다. |
| 3 | story_promise | "촛불은 아빠가 와야 불 거야." / 오늘은 꼭 간다. |
| 4 | story_noelev | 엘리베이터는 마침 정기 점검 중이었다. / 계단으로 간다. 다섯 층만 내려가면 된다. |

### 계단 (층을 내려갈 때마다 1장면. 2026-10-01 휴대폰 장면으로 바꿈)

김 과장의 눈으로 본 계단 그림(story_stairs: 계단 아래 문, 오른손의 가방)이 걸음마다 출렁이며 아래층 문 쪽으로 다가간다. 그 한 장면 안에서 아래 순서로 진행된다.

| 순서 | 화면 | 다음으로 넘어가는 법 |
|---|---|---|
| 1. 걷기 | 위에 층 표시(예: 5F → 4F), 아래에 걷는 글. 8걸음 중 3걸음째에서 멈춘다 | 저절로 (누르면 바로 2로) |
| 2. 진동 | 휴대폰이 아래에서 반쯤 올라와 떨리고 "지잉" 소리가 난다. 휴대폰 화면에 "우리 딸" 알림, 아래에 진동 글. 볼 때까지 1.4초마다 다시 울린다 | 화면을 누름 |
| 3. 문자 보기 | 왼손에 든 휴대폰이 다 올라오고 문자가 하나씩 나타난다. 진동 소리는 바로 멈춘다 | 누름 (문자가 아직 나타나는 중이면 먼저 다 보여 줌) |
| 4. 휴대폰 넣기 | 휴대폰을 내리고 남은 계단을 마저 내려간다. 아래에 마지막 글 | 누르면 아래층으로 |

| 구간 | 층 표시와 걷는 글 | 진동 글 | 휴대폰 알림 | 문자 | 휴대폰을 넣은 뒤 글 |
|---|---|---|---|---|---|
| 5층에서 4층 | 5F → 4F / 비상계단으로 내려간다. | 문자가 왔다. | 새 메시지 | 딸: "아빠 언제 와?" / 김 과장: "금방 가." | (걷는 글 그대로) |
| 4층에서 3층 | 4F → 3F / 한 층 더. | 주머니 속 휴대폰이 떨린다. | 부재중 전화 2통 | 부재중 전화 / 부재중 전화 | 회의 중이라 받지 못했다. |
| 3층에서 2층 | 3F → 2F / 다리가 후들거린다. | 문자가 왔다. | 새 메시지 2개 | 딸: "케이크 꺼내 놨어." / "촛불은 아직 안 켰어." | (걷는 글 그대로) |
| 2층에서 1층 | 2F → 1F / 마지막 계단이다. | 문자가 왔다. | 새 메시지 | 딸: "아빠, 나 졸려." | 1층이다. 이 문만 나서면 된다. |

예전의 계단 이야기 그림 4장(story_stair1~4: 문자를 보는 김 과장, 부재중 전화, 케이크를 꺼내 놓은 집, 1층 문 앞)은 이 휴대폰 장면으로 바뀌어 쓰지 않는다 (`_old/` 에 보관).

### 결말 (3장면, 부장님을 이긴 뒤. 굿엔딩 / 노말엔딩)

시작부터 부장님을 잡을 때까지 **15분 안**이면 굿엔딩, 넘으면 노말엔딩 (`GOOD_ENDING_TIME`). 앞 두 장면은 같고 마지막 장면만 다르다.

| 번호 | 그림 파일 | 글 |
|---|---|---|
| 1 | story_end1 | 부장님: "...나도 우리 애 생일을 세 번 놓쳤지." / "들어가 봐. 뛰어." |
| 2 | story_clear | 지하철 창가. 가방을 꼭 안았다. |
| 3 굿엔딩 | story_home_good | 문을 열자마자 아이가 달려와 안겼다. / "촛불은 아빠가 와야 분다고 했잖아." 같이 불었다. |
| 3 노말엔딩 | story_home | 밤 11시 50분. 식탁에서 졸던 아이를 깨웠다. / "아빠 왔어. 같이 촛불 불자." |

결말 뒤에 결과 창이 나온다: 굿엔딩 "생일 축하해. 아빠 왔어." / 노말엔딩 "생일 축하해. 늦어서 미안." + 어느 엔딩인지와 기준 시간, 걸린 시간, 처치 수, 레벨. 결과 창에는 그림이 없다 (바로 앞 장면과 같은 그림이 두 번 나오지 않게, 2026-09-30).

### 게임오버 (죽은 이유마다 1장면, 그 뒤 결과 창)

층 보스가 나와 있을 때 죽으면 그 보스의 장면, 아니면 일반 적 장면. 결과 창에는 같은 그림과 "새벽 2시. 문자가 와 있었다. / "아빠 나 먼저 잘게. 사랑해."" 가 나온다 (2026-09-30 사용자가 정한 문구).

| 죽은 이유 | 그림 파일 | 글 |
|---|---|---|
| 일반 적 | story_over_work | 일에 파묻혔다. 자정이 지났다. / 휴대폰은 서류 더미 밑에서 울리고 있었다. |
| 5층 옆 팀 팀장 | story_over_5f | "이것만" 이 열 개가 됐다. / 옆 팀 일을 새벽까지 봐 줬다. |
| 4층 끝나지 않는 주간 회의 | story_over_4f | 회의는 끝나지 않았다. / 안건 12번에서 눈을 떴다. 새벽 2시. |
| 3층 인사팀장 | story_over_3f | 면담은 길었다. / "평가에 반영하겠습니다." 딸 생일 이야기는 꺼내지 못했다. |
| 2층 감사팀장 | story_over_2f | 영수증 한 장을 찾다 밤이 샜다. / 찾았을 땐 이미 자정이었다. |
| 1층 부장님 | story_over_1f | "한 잔만" 이 세 병이 됐다. / 휴대폰이 계속 울렸다. 받지 못했다. |

예전 게임오버 그림(story_over, 책상에 엎드려 잠듦)은 더 쓰지 않는다 (`_old/` 에 보관).

## 3. 조작

| 키 | 동작 |
|---|---|
| Enter, Space, 클릭 | 다음 장면. 계단 장면에서는 한 단계씩: 걷는 중이면 휴대폰이 울리는 데까지 바로 감 → 진동 중이면 휴대폰 보기 → 문자를 보는 중이면 휴대폰 넣기 → 그다음은 아래층 |
| Esc | 컷신 전체 건너뛰기 (진동 소리도 바로 멈춤) |

## 4. 그림

이야기 그림 15장, 계단 휴대폰 장면용 그림 2장, 비상계단 문 아이콘 1장이다. 그림에는 글자를 넣지 않았다. 문자 내용은 게임이 아래 글이나 휴대폰 화면 위에 글자로 써서 보여 준다.

| 묶음 | 그림 |
|---|---|
| 시작 | story_open, story_gift, story_promise, story_noelev |
| 계단 | story_stairs (1인칭 계단 배경), phone_hand (왼손에 든 휴대폰. 화면은 비워 두고 게임이 알림과 문자를 씀), avatar_kid (휴대폰 화면의 딸 사진. 굿엔딩 그림에서 얼굴만 오려 냄) |
| 결말 | story_end1, story_clear, story_home_good (굿엔딩), story_home (노말엔딩) |
| 게임오버 | story_over_work, story_over_5f, story_over_4f, story_over_3f, story_over_2f, story_over_1f |
| 게임 안 | stairs (보스를 잡으면 나타나는 비상계단 문 아이콘) |

쓰지 않게 된 엘리베이터 그림, 예전 결말 그림, 옆에서 본 계단 그림(story_stairs_side), 계단 이야기 그림 story_stair1~4 (10-01 휴대폰 장면으로 바뀜)는 `assets/office/_old/` 에 보관했다.

## 5. 고치고 싶을 때

| 고치고 싶은 것 | 방법 |
|---|---|
| 대사 | `CUTSCENES` 표의 `lines` 를 고친다 |
| 장면 추가 | `panels` 에 한 줄 추가 (`img` 는 assets/office 폴더의 그림 이름) |
| 버튼 글자 | `doneLabel` |
| 글이 나타나는 속도 | `CUTSCENE_LINE_DELAY` |
| 굿엔딩 기준 시간 | `GOOD_ENDING_TIME` (초, 지금 15분) |
| 계단을 내려가는 속도 | `STAIRS_WALK_TIME` (초) |
| 걸음 수, 출렁임, 좌우 흔들림 | `STAIRS_WALK_STEPS`, `STAIRS_WALK_BOB`, `STAIRS_WALK_SWAY` |
| 얼마나 다가가는지 | `STAIRS_WALK_ZOOM_FROM` → `STAIRS_WALK_ZOOM_TO` (배율) |
| 다가가는 곳 | `STAIRS_WALK_FOCUS` (그림 속 아래층 문의 위치 %. 계단 그림을 바꾸면 맞춰야 함) |
| 계단 휴대폰의 글 | `CUTSCENES.stairs` 의 `phone`: `ring` (진동이 올 때 아래 글), `notice` (휴대폰 알림), `chat` (문자. `me: true` = 김 과장이 보낸 것, `missed: true` = 부재중 전화), `after` (휴대폰을 넣은 뒤 글. 없으면 걷는 글) |
| 휴대폰이 울리는 걸음 | `STAIRS_PHONE_STEP` (8걸음 중 지금 3걸음째) |
| 문자를 보낸 사람 이름과 사진 | `PHONE_CONTACT` ("우리 딸"), `PHONE_AVATAR` |
| 문자가 하나씩 나타나는 간격 | `PHONE_BUBBLE_DELAY` (0.7초) |
| 진동이 다시 오는 간격 | `PHONE_BUZZ_REPEAT` (1.4초. CSS 의 phone-shake 길이와 같게 맞출 것) |
| 진동 소리 (길이, 높이, 떨림, 크기) | `PHONE_BUZZ_LENGTH`, `PHONE_BUZZ_PITCH`, `PHONE_BUZZ_RATTLE`, `PHONE_BUZZ_VOLUME` (소리 파일 없이 게임이 직접 만듦) |
| 진동 중과 문자 볼 때의 버튼 글자 | `PHONE_OPEN_LABEL`, `PHONE_CLOSE_LABEL` |
