## 3. 직접 해 보기

공개 링크: https://cmj1203.github.io/office-escape/ (누구나 열 수 있음). 아래는 내 컴퓨터에서 고친 것을 바로 볼 때.

서버는 이미 떠 있다 (2026-09-17 부터 8765 포트, 이 게임 폴더를 보여 줌. 09-30 에 새 버전이 나오는 것을 확인함). 주소만 열면 된다.

| 순서 | 할 일 |
|---|---|
| 1 | 크롬에서 `http://[::1]:8765/index.html?v=3` 열기 |

주의할 점:

| 상황 | 설명 |
|---|---|
| 화면이 예전 그대로 보임 | 주소 끝의 `v=3` 숫자를 바꿔서 다시 연다 (크롬이 예전 파일을 기억하고 있어서 그렇다). 그림은 `index.html` 의 `ASSET_VERSION` 값으로 따로 관리되어, 그림을 바꾼 뒤에는 그 값을 바꿔야 새 그림이 보인다 |
| `127.0.0.1:8765` 로 열면 다른 화면이 나옴 | 그 주소는 다른 프로젝트(검수 뷰어)가 쓰고 있다. 반드시 `[::1]` 로 연다 |
| 주소가 안 열림 (맥을 재부팅한 뒤 등) | 터미널에서 `cd ~/survivor-game && python3 -m http.server 8765` 를 실행한 뒤 다시 연다 |
| 서버 실행 명령이 "Address already in use" 오류를 냄 | 이미 떠 있다는 뜻이다. 그냥 주소를 열면 된다 |

## 5. 난이도 숫자 고치는 곳

전부 `index.html` 안에 있다. 숫자 하나만 고치면 된다.

| 고치고 싶은 것 | 찾을 이름 | 지금 값 |
|---|---|---|
| 층에 도착한 뒤 몇 레벨 오르면 보스가 나오는지 | `FLOORS` 표의 `bossLevels` | 5층 4, 4층 4, 3층 5, 2층 5, 1층(부장님) 8 (10-01 에 5 → 8) |
| 가질 수 있는 무기 수 | `MAX_WEAPONS` | 4 (10-01 에 6 → 4. 다 차면 새 무기 카드와 탕비실 서랍이 안 나옴) |
| 가질 수 있는 아이템 수 | `PASSIVE_MAX_SLOTS` | 4 (10-01 에 6 → 4. 점심 메뉴판도 한 칸을 차지함) |
| 층에 도착한 뒤 보스가 나오기까지 최소 시간 | `FLOOR_BOSS_MIN_TIME` | 30초 |
| 굿엔딩 기준 시간 | `GOOD_ENDING_TIME` | 15분 (층마다 3분 상한을 다 채우면 넘음. 첫 값이라 체감 후 조정) |
| 층마다 물건 종류·수·크기 | `FLOORS` 표의 `props` | 5층 책상 16, 4층 탁자 9, 3층 커피 머신 8, 2층 복합기 6 + 캐비닛 12, 1층 안내 데스크 3 + 화분 12 |
| 4층 회의 구역 간격 / 느려지는 정도 | `MEETING_INTERVAL` / `MEETING_SLOW` | 10초 / 절반 |
| 3층 믹스커피 간격 / 효과 시간 | `COFFEE_INTERVAL` / `COFFEE_BUFF_TIME` | 12초 / 8초 (걸음 1.3배, 무기 간격 0.75배) |
| 2층 전화벨 간격 / 전화기 수 | `PHONE_RING_INTERVAL` / `PHONE_RING_COUNT` | 28초 / 14대 |
| 1층 어둠 / 밝은 원 크기 | `LOBBY_DARK` / `LOBBY_LIGHT_RADIUS` | 0.85 / 반지름 220 |
| 레벨을 못 채워도 보스가 나오는 시간 | `FLOOR_FIGHT_TIME` | 180초 (3분) |
| 일반 적 체력이 시간에 따라 느는 정도 | `ENEMY_HP_PER_MINUTE_BASE`, `ENEMY_HP_PER_MINUTE` | 0.10, 0.06 (전엔 0.14, 0.12) |
| 층 보스 체력 | `FLOORS` 표의 `hp` | 5층 20, 4층 280, 3층 640, 2층 900 (09-30 에 2배로) |
| 부장님 체력 | `BOSS_TYPE` 의 `hp`, `BOSS_HP_PER_LEVEL` | 5000 (09-30 에 2배로), 레벨당 120 |
| 보스가 공격하는지 | `BOSS_ATTACKS` | false (탄환·부하·닿는 피해 전부 없음. 쫓아오기만 함) |
| 전체 난이도 | `DIFFICULTY` | 1.5 |
| 적이 나오는 간격 (처음 / 최소) | `SPAWN_START` / `SPAWN_MIN` | 0.7초 / 0.2초 (09-30 "너무 쉽다" 의견에 0.8 / 0.25 에서 줄임. 더 어렵게 = 더 작게. 0.6 은 첫 무기가 못 따라가 적이 무한히 쌓여 되돌림) |
| 적 속도가 빨라지는 정도 / 최대 | `ENEMY_SPEED_PER_MINUTE` / `ENEMY_SPEED_CAP` | 1분마다 +4.5% / 최대 1.4배 |
| 적 공격이 세지는 정도 / 최대 | `ENEMY_DAMAGE_PER_MINUTE` / `ENEMY_DAMAGE_CAP` | 1분마다 +8% / 최대 2.4배 |
| 맞은 뒤 무적 시간 | `INVINCIBLE_TIME` | 0.7초 (짧을수록 몰렸을 때 아픔) |
| 안 읽은 메일 속도 | `ENEMY_TYPES` 의 `bat` `speed` | 90 (예전 80) |
| 캐릭터 그림 크기 | `SPRITE_SCALE` | 2.0 |
| 무기 그림 크기 | `WEAPON_SPRITE_SCALE` | 0.9 (예전 1.5. 절반인 0.75 는 볼펜이 안 보여 조금 키움) |
| 걷는 그림이 바뀌는 속도 | `WALK_FPS` | 8 (1초에 8장) |

## 6. 자동 검사로는 알 수 없었던 것

| 항목 | 설명 |
|---|---|
| 재미와 난이도 | 자동 조작으로만 돌렸다. 사람이 하는 것과 다르다 |
| 부장님 | 10-01 측정 (자동 조작 한 번): 8레벨 조건에서 1층 도착 163초 뒤 레벨 47 로 부장님을 만났고 (5레벨일 때는 92초), 90초 동안 체력 15960 중 4164 (26%) 를 깎았다. 사람이 해 보고 너무 튼튼하거나 약하면 알려 주기 |
| 무기·아이템 4개 제한 | 자동 조작은 무기 4개에 강화가 몰려 오히려 세졌다: 4층·3층·2층 보스를 모두 90초 안에 잡음 (제한 전에는 셋 다 못 잡음), 부장님에게 준 피해도 9% → 26%. 한 번씩 돌린 결과라 운도 섞여 있다. 사람에게도 쉬워졌는지 확인 필요 |
| 진동 소리 | 소리 파일 없이 게임이 직접 만든다. 크기와 느낌은 사람 귀로 확인 필요 (검토 영상에 소리가 들어 있음) |
| 실제 공개 링크 | 10-01 부터 공개됨. 휴대폰 등 다른 기기에서는 아직 안 해 봄 |
