# 야근 탈출 개편: 이름표와 스토리

작성일: 2026-09-29. 갱신: 2026-09-30.
상태: 게임에 반영됨 (브랜치 office-reskin, 커밋 전). 이름과 대사를 고치려면 index.html 의 해당 표를 고치면 된다.

달라진 점: 회식은 의자가 아니라 소주병. 제목은 "아빠는 퇴근 중" (2026-10-01 결정. 처음 이름은 "야근 탈출"). 일시정지 창 제목은 "잠깐 화장실".

## 2. 스토리

| 시점 | 화면에 나오는 글 |
|---|---|
| 시작 | 오후 6시. 가방을 들었다. 메일 알림이 울렸다. |
| 시작 (둘째 줄) | 오늘은 딸의 여섯 번째 생일이다. 오늘은 꼭 간다. |
| 게임오버 | 책상에 엎드려 잠들었다. / 다음 날, 오후 6시. 12년째. |
| 클리어 | 집에 도착해 잠든 딸 곁에서 촛불 하나를 켠다. "생일 축하해. 늦어서 미안." |

게임 속 시계는 18:00 (칼퇴할 시간) 에서 시작해 23:00 에 부장님이 나타난다. 한 층에 한 시간씩 흐른다. 막차 설정은 뺐다 (2026-09-30).

## 3. 층 구성 (한 층에 약 4분)

| 층 | 장소 | 새로 나오는 적 | 층 보스 | 도착 문구 |
|---|---|---|---|---|
| 5F | 사무실 | 안 읽은 메일 | 옆 팀 팀장 | 5F 사무실. 퇴근 시간이다. |
| 4F | 회의실 | 회의 | 끝나지 않는 주간 회의 | 4F 회의실. 불이 아직 켜져 있다. |
| 3F | 탕비실과 복도 | 메신저 | 인사팀장 | 3F 탕비실. 커피 냄새가 난다. |
| 2F | 서버실과 총무팀 | 전화기, 분기 보고서 | 감사팀장 | 2F 총무팀. 전화가 울린다. |
| 1F | 로비 | 전부 | 부장님 | 1F 로비. 누군가 기다리고 있다. |

한 층의 흐름: 도착 -> 싸우며 레벨을 올림 -> 그 층에서 정해진 만큼(4, 4, 5, 5, 5 레벨) 오르거나 늦어도 3분이 지나면(먼저 오는 쪽) 층 보스 등장(보스는 공격하지 않고 쫓아오기만 하며, 체력이 많다. 그동안 몰려오는 일반 적이 위협) -> 보스를 잡으면 비상계단 문이 열림 -> 김 과장의 눈으로 계단을 내려감 -> 아래층. (엘리베이터는 정기 점검 중이라 탈 수 없다)

층마다 길을 막는 물건과 규칙이 하나씩 있다 (5층 책상, 4층 회의 구역, 3층 믹스커피, 2층 전화벨, 1층 불 꺼진 로비). 자세한 것은 `05-floor-features.md` 7장.

## 4. 적

코드 키는 지금 게임에 있는 이름이다. 움직임은 그대로 두고 이름과 그림만 바꾼다.

| 새 이름 | 움직임 | 지금 코드 키 | 비고 |
|---|---|---|---|
| 안 읽은 메일 | 약하고 빠름. 떼로 몰려옴 | bat | 떼 이벤트 이름은 "전체 메일" |
| 회의 | 죽으면 작은 회의 2개로 갈라짐 | spider | 작은 것 이름은 "후속 회의" |
| 메신저 | 빠르게 쫓아옴 | ghost | 말풍선 모양 |
| 전화기 | 걷다가 멈춰서 울린 뒤 돌진 | crab | 울릴 때 옆으로 피하면 빗나감 |
| 분기 보고서 | 크고 느리고 튼튼함 | cyclops | 서류 더미 |
| 회식 | 소주병들이 원으로 둘러싸고 조여 옴 | flower | 처음에는 의자였으나 소주병으로 교체 |
| 추가 업무 | 간식 상자인 척하다가 덤벼듦 | mimic | |
| 부장님 | 마지막 보스 | boss (그림 키 wizard) | |

주의: 지금 코드의 등장 순서는 bat -> crab -> spider -> ghost -> cyclops 이다. 위 층 구성에 맞추려면 등장 순서와 능력치를 다시 배치해야 한다.

엘리트 (금색 고리가 붙은 큰 적, 잡으면 상자) 의 새 이름: "팀장님이 직접 보낸 업무".
